# Implementation Plan: Game Start & Drawer Flow

**Branch**: `002-game-start-drawer` | **Date**: 2026-06-05 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-game-start-drawer/spec.md`

**Prerequisite**: Scenario 1 (`specs/001-scribble-game/`) fully implemented and validated.

## Summary

Extend the `startRoom()` flow to record a drawer (host = participants[0]) and a secret
word (always `"rocket"` = `STARTER_WORDS[0]`) on the room. Update `toRoomSnapshot()` to
filter the word out of responses sent to non-drawers. Add drawer identification and
word display to the game screen.

## Implementation Sequence

### Backend

1. `backend/src/models/game.ts` — add `drawerId?: string` and `currentWord?: string`
   to both `Room` and `RoomSnapshot`
2. `backend/src/services/roomStore.ts`:
   - In `startRoom()`: set `room.drawerId = room.hostId` and
     `room.currentWord = STARTER_WORDS[0]` before `saveRoom`
   - In `toRoomSnapshot()`: remove the `void viewerParticipantId` no-op; always include
     `drawerId` when set; include `currentWord` only when
     `viewerParticipantId === room.drawerId`

### Frontend

3. `frontend/src/services/api.ts` — add `drawerId?: string` and `currentWord?: string`
   to `RoomSnapshot`
4. `frontend/src/pages/GamePage.tsx` — read `participantId` and `room` from store;
   derive `isDrawer = participantId === room?.drawerId`; find drawer's display name;
   render drawer name to all players; render `room.currentWord` only when `isDrawer`

### Validation

5. Two-tab walkthrough per `specs/002-game-start-drawer/quickstart.md`
6. `npm run build` in both `backend/` and `frontend/` — must exit 0
