# Implementation Plan: Game Start & Drawer Flow

**Branch**: `002-game-start-drawer` | **Date**: 2026-06-04 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-game-start-drawer/spec.md`

**Depends on**: Scenario 1 — `hostId`, `startRoom()`, `RoomStatus` union all already in place.

---

## Summary

Extend the game-start flow to assign the host as drawer, select the secret word deterministically,
and filter the word from non-drawer snapshots. Update the game screen to show role-aware content:
a word banner above the canvas for the drawer, a passive canvas placeholder for guessers, and a
"Drawer" label visible to all players.

## Data Flow

### Game Start (extends S1)

```
Host clicks Start Game
  → api.startRoom(room.code, participantId)
  → POST /rooms/:code/start { participantId }
  → roomStore.startRoom(code, participantId)
     → [existing S1 checks: host, ≥2 players]
     → room.status = "playing"
     → room.drawerId = room.hostId          ← NEW
     → room.secretWord = STARTER_WORDS[0]   ← NEW
     → return toRoomSnapshot(room, participantId)
        → includes secretWord (caller is drawer)
  → host store: setRoomSnapshot(room with secretWord)
  → host navigates to /game → sees banner "Your word: rocket"

Non-host lobby poll detects status === "playing"
  → store has latest snapshot (drawerId present, secretWord absent for guesser)
  → navigate to /game → sees drawer label, passive canvas, enabled guess form
```

### Role Filtering in toRoomSnapshot

```
toRoomSnapshot(room, viewerParticipantId):
  snapshot = {
    code, status, participants, hostId,
    drawerId: room.drawerId,          // always include when set
    availableWords, roles
  }

  if viewerParticipantId === room.drawerId:
    snapshot.secretWord = room.secretWord  // include for drawer only

  return snapshot
```

### Game Screen Rendering

```
GamePage mounts
  → room = useRoomState().room
  → participantId = useRoomState().participantId
  → isDrawer = room.drawerId === participantId

  if isDrawer:
    → render word banner above canvas: "Your word: rocket"
    → render canvas placeholder: "Draw here — drawing enabled in next step"
    → render <GuessForm disabled={true} />

  else (guesser):
    → no banner
    → render canvas placeholder: "Waiting for drawer..."
    → render <GuessForm disabled={false} />

  player list: show "Drawer" badge next to participant whose id === room.drawerId
```

## Implementation Sequence

### Step 1 — Backend + Frontend type sync

Files: `backend/src/models/game.ts`, `frontend/src/services/api.ts`

- Add `drawerId?: string` and `secretWord?: string` to `Room` interface (backend)
- Add `drawerId?: string` and `secretWord?: string` to `RoomSnapshot` interface (backend)
- Mirror both fields as optional on frontend `RoomSnapshot`
- Verify both TypeScript builds pass

### Step 2 — Backend: extend startRoom and toRoomSnapshot

File: `backend/src/services/roomStore.ts`

- In `startRoom()`: after `room.status = "playing"`, set `room.drawerId = room.hostId`
  and `room.secretWord = STARTER_WORDS[0]`
- In `toRoomSnapshot()`: replace `void viewerParticipantId` with filtering logic —
  always include `drawerId`; include `secretWord` only when
  `viewerParticipantId === room.drawerId`

### Step 3 — Frontend: role-aware GamePage

File: `frontend/src/pages/GamePage.tsx`

- Derive `isDrawer = room.drawerId === participantId`
- Add word banner above canvas rendered only when `isDrawer && room.secretWord`
  (text: `"Your word: ${room.secretWord}"`)
- Update canvas placeholder: drawer sees "Draw here…", guesser sees "Waiting for drawer…"
- Pass `disabled={isDrawer}` to `<GuessForm />`
- Add "Drawer" badge in player info for the participant whose id is `room.drawerId`

## Risks

| Risk | Mitigation |
|------|-----------|
| `secretWord` leaks to guesser if `participantId` not passed on fetch | Safe default: omit word when `viewerParticipantId` is undefined |
| `room.drawerId` undefined on lobby snapshot causes frontend crash | Guard evaluates `undefined === participantId` as `false` — safe |
| `room.secretWord` undefined in banner before game starts | Banner only renders when `isDrawer && room.secretWord` — guarded |
