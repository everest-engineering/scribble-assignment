# Implementation Plan: Gameplay Interaction

**Branch**: `003-gameplay-interaction` | **Date**: 2026-06-05 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/003-gameplay-interaction/spec.md`

**Prerequisites**: Scenarios 1 and 2 (`001-scribble-game`, `002-game-start-drawer`) fully implemented.

## Summary

Add interactive drawing (HTML5 canvas with stroke capture), canvas clear, guess submission
with validation and scoring, guess history, and game screen polling. Three new backend
endpoints; no new frontend libraries.

## Technical Context

**Language/Version**: TypeScript — Node.js 18+ (backend), Vite + React 18 (frontend)

**Primary Dependencies**: Express + Zod (backend); HTML5 Canvas API, React (frontend).
No new npm dependencies.

**Storage**: In-memory `Map<string, Room>` — extending existing `Room` type with
`canvasStrokes`, `guesses`, and `scores`.

**Testing**: Manual two-browser-tab validation per `quickstart.md`.

**Target Platform**: localhost dev (Node.js 3001 + Vite 5173)

**Project Type**: Web app — `backend/` + `frontend/`

**Performance Goals**: Canvas and guess history visible to all players within ~2 s.

**Constraints**: No new libraries (HTML5 Canvas API only); server is authoritative for
all game state; no client-side scoring.

## Implementation Sequence

### Backend

1. `backend/src/models/game.ts` — add `Point`, `Stroke` (= `Point[]`), `Guess` types;
   extend `Room` with `canvasStrokes`, `guesses`, `scores`; extend `RoomSnapshot` with
   same three fields
2. `backend/src/api/schemas.ts` — add `strokeSchema`, `clearCanvasSchema`, `guessSchema`
3. `backend/src/services/roomStore.ts` — initialise fields in `startRoom()`; add
   `addStroke()`, `clearCanvas()`, `submitGuess()`; include fields in `toRoomSnapshot()`
4. `backend/src/api/rooms.ts` — add `POST /:code/stroke`, `POST /:code/clear`,
   `POST /:code/guess` routes

### Frontend

5. `frontend/src/services/api.ts` — add `Point`, `Stroke`, `Guess` types; extend
   `RoomSnapshot`; add `addStroke()`, `clearCanvas()`, `submitGuess()` to `api` object
6. `frontend/src/state/roomStore.ts` — add `addStroke()`, `clearCanvas()`,
   `submitGuess()` methods
7. `frontend/src/pages/GamePage.tsx` — add `setInterval` polling (~2 000 ms); wire
   canvas `<canvas>` element with mouse events for drawer (send stroke on mouseup);
   render canvas as view-only for guessers; render scoreboard from `room.scores`;
   render guess history from `room.guesses`
8. `frontend/src/components/GuessForm.tsx` — implement `handleSubmit`: trim, validate
   non-empty client-side, call `roomStore.submitGuess()`; show error on empty
9. `frontend/src/components/Scoreboard.tsx` — render scores from `room.scores`
   (received via `useRoomState()`)

### Validation

10. Two-tab walkthrough per `specs/003-gameplay-interaction/quickstart.md`
11. `npm run build` in both `backend/` and `frontend/` — must exit 0
