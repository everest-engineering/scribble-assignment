# Result, Restart & Final Validation

## Acceptance Criteria
1. When a correct guess is made, round ends and all players see result.
2. Result shows: secret word, final scores, full guess history.
3. Host can click Restart to return everyone to lobby.
4. Restart preserves player list, clears round state (drawing, guesses, scores).

## Edge Cases
- Restart works with same players (no duplicate re-join needed).
- Restart button visible only to host.
