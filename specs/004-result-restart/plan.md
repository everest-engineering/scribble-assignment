# Implementation Plan: Result, Restart & Final Validation

**Branch**: `004-result-restart` | **Date**: 2026-06-05 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/004-result-restart/spec.md`

**Prerequisites**: Scenarios 1–3 (`001`, `002`, `003`) fully implemented and validated.

## Summary

Add `"result"` to `RoomStatus`; expose `POST /rooms/:code/end` (host only → status
becomes `"result"`) and `POST /rooms/:code/restart` (host only → resets to `"lobby"`).
Update `toRoomSnapshot` to reveal `currentWord` in result state. Add a `ResultPage`
with its own polling and the host's Restart button.

## Technical Context

**Testing**: Manual two-browser-tab validation per `quickstart.md`.

**Target Platform**: localhost dev (Node.js 3001 + Vite 5173)

**Project Type**: Web app — `backend/` + `frontend/`

**Constraints**: No new libraries; polling-driven navigation reused from prior scenarios.

## Implementation Sequence

### Backend

1. `backend/src/models/game.ts` — add `"result"` to `RoomStatus`
2. `backend/src/api/schemas.ts` — add `endRoundSchema` and `restartRoomSchema`
   (both `{ participantId: string }`)
3. `backend/src/services/roomStore.ts`:
   - Add `endRound(code, participantId)`: validate host + active, set status `"result"`,
     saveRoom
   - Add `restartRoom(code, participantId)`: validate host + result state, reset
     `canvasStrokes/guesses/scores/currentWord/drawerId` to empty/undefined, set status
     `"lobby"`, saveRoom
   - In `toRoomSnapshot()`: reveal `currentWord` unconditionally when
     `room.status === "result"` (in addition to existing drawer-only rule for "active")
4. `backend/src/api/rooms.ts` — add `POST /:code/end` and `POST /:code/restart` routes

### Frontend

5. `frontend/src/services/api.ts` — add `"result"` to status union; add `endRound()`,
   `restartGame()` methods
6. `frontend/src/state/roomStore.ts` — add `endRound()`, `restartGame()` methods
7. `frontend/src/routes/index.tsx` — import `ResultPage`; add `<Route path="/result">`
8. `frontend/src/pages/GamePage.tsx` — in polling callback, navigate to `/result` when
   `room?.status === "result"` (alongside existing `"active"` guard)
9. `frontend/src/pages/ResultPage.tsx` — new component: redirect to `/` if no room;
   poll ~2 000 ms, navigate to `/lobby` on `status === "lobby"`; render secret word,
   scoreboard, guess history; show End Round button for host during "active" (N/A here)
   and Restart button for host only; call `roomStore.restartGame()` on Restart click

### Validation

10. Two-tab walkthrough per `specs/004-result-restart/quickstart.md`
11. `npm run build` in both `backend/` and `frontend/` — must exit 0
