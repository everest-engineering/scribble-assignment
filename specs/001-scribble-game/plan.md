# Implementation Plan: Scribble Drawing Game

**Branch**: `001-scribble-game` | **Date**: 2026-06-04 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/001-scribble-game/spec.md`

## Summary

Brownfield enhancement of the Scribble starter. Four missing capability groups — room
host tracking, game start with role assignment, drawing/guessing gameplay, and
result/restart lifecycle — are added as targeted changes to existing files. No new
libraries. All real-time sync via polling at ~2s intervals. In-memory state only.

## Technical Context

**Language/Version**: TypeScript (strict); Node.js 18+ (backend); Vite + React 18 (frontend)

**Primary Dependencies**: Express + Zod (backend); React + react-router-dom (frontend)

**Storage**: In-memory `Map<string, Room>` — no persistence; restarting backend clears all rooms

**Project Type**: Web application — `backend/` + `frontend/` monorepo structure

**Constraints**: No WebSockets, no database, no auth, no new routing/state libs;
both `npm run build` must pass before PR

**Scale/Scope**: Local development, 2-4 player sessions

## Backend State Model Changes

### `backend/src/models/game.ts`

```
RoomStatus: "lobby" | "playing" | "result"   (was: "lobby" only)

Room — additions:
  hostId: string
  drawer?: string
  secretWord?: string
  canvasData?: string
  guesses: Guess[]
  scores: Record<string, number>

New type Guess:
  id: string
  participantId: string
  playerName: string
  text: string
  correct: boolean
  timestamp: string

RoomSnapshot — additions:
  hostId: string
  drawer?: string
  secretWord?: string          (conditional: drawer during play, all during result)
  canvasData?: string
  guesses: Guess[]
  scores: Record<string, number>
```

### `backend/src/services/roomStore.ts`

| Change | Description |
|--------|-------------|
| `createRoomSchema` / `joinRoomSchema` | `z.string().optional()` → `z.string().trim().min(1)` |
| `createParticipant` | Remove `displayName()` fallback; name required + pre-trimmed by Zod |
| `createRoom` | Add `hostId`, `guesses: []`, `scores: {}` to Room init |
| `toRoomSnapshot` | Activate `viewerParticipantId`; apply secretWord visibility rule |
| `startGame(code, requesterId)` | 403 if non-host; 400 if <2 players; set playing state |
| `submitGuess(code, participantId, text)` | 403 if drawer; 400 if empty; score once per player |
| `updateCanvas(code, participantId, data)` | 403 if non-drawer; update canvasData |
| `endGame(code, requesterId)` | 403 if non-host; set status="result" |
| `restartGame(code, requesterId)` | 403 if non-host; reset round fields; keep participants |

### New routes — `backend/src/api/rooms.ts`

```
POST /:code/start    → startGame
POST /:code/canvas   → updateCanvas
POST /:code/guess    → submitGuess
POST /:code/end      → endGame
POST /:code/restart  → restartGame
```

## Data Flow

```
1. Create Room
   POST /rooms → hostId set → participantId stored in client → Lobby

2. Join Room
   POST /rooms/:code/join → participantId stored in client → Lobby

3. Lobby Polling
   setInterval(fetchRoom, 2000) → status change detected → auto-navigate to Game

4. Start Game (host)
   POST /rooms/:code/start → status="playing", drawer+word set → all pollers navigate

5. Drawing (drawer)
   mousedown/mousemove/mouseup → render locally → on mouseup: POST /rooms/:code/canvas

6. Canvas Sync (guessers)
   setInterval(fetchRoom, 2000) → canvasData → drawImage on <canvas>

7. Guess Submission (guessers)
   GuessForm → trim + validate → POST /rooms/:code/guess → scores + guesses updated

8. Guess History Sync (all)
   setInterval(fetchRoom, 2000) → guesses array → render list

9. End Round (host)
   POST /rooms/:code/end → status="result" → all pollers see result screen

10. Restart (host)
    POST /rooms/:code/restart → status="lobby" → all pollers navigate back to Lobby
```

## Implementation Sequence

### Scenario 3 — Gameplay Interaction

- **S3-A**: Add `Guess` type to models

## Risks

| Risk | Mitigation |
|------|-----------|
| Canvas base64 payload size | Fixed 600×450 canvas; ~50-100 KB; acceptable on localhost |
| Polling race condition | `fetchRoom` fire-and-forget; errors silently caught; UI shows last known state |
| Late joiner mid-game | FR-018: redirect on poll; score 0; drawer unchanged |
| Double End Round click | Idempotent: second `endGame` on "result" room is a no-op |
