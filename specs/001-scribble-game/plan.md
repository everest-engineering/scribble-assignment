# Implementation Plan: Room Setup & Lobby

**Branch**: `001-scribble-game` | **Date**: 2026-06-05 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-scribble-game/spec.md`

## Summary

Add host tracking, player-name validation, automatic lobby polling (~2 s), and a
host-only Start Game flow that transitions all players to the game screen. The existing
Express backend and React frontend are extended in-place — no new libraries, no new
routing infrastructure.

## Technical Context

**Language/Version**: TypeScript — Node.js 18+ (backend), Vite + React 18 (frontend)

**Primary Dependencies**: Express + Zod (backend); React Router, custom `RoomStore`
with `useSyncExternalStore` (frontend). No new dependencies for Scenario 1.

**Storage**: In-memory `Map<string, Room>` in `backend/src/services/roomStore.ts`

**Testing**: Manual two-browser-tab validation per `quickstart.md`

**Target Platform**: localhost dev (Node.js 3001 + Vite 5173)

**Project Type**: Web app — `backend/` + `frontend/`

**Performance Goals**: Lobby participant list visible to all players within ~2 s of a
change, with no manual action required.

**Constraints**: No WebSockets, no auth, no external DB, no new top-level dependencies.

## Implementation Sequence

### Backend

1. `backend/src/models/game.ts` — extend `RoomStatus` to `"lobby" | "active"`; add
   `hostId: string` to `Room` and `RoomSnapshot` interfaces
2. `backend/src/api/schemas.ts` — make `playerName` required (`z.string().min(1)`
   after trim); add `startRoomSchema` (`{ participantId: string }`)
3. `backend/src/services/roomStore.ts` — set `hostId` from first participant on
   `createRoom`; apply trim in `createParticipant`; add `startRoom(code, participantId)`
   that validates host + count and flips status; surface `hostId` in `toRoomSnapshot`
4. `backend/src/api/rooms.ts` — add `POST /:code/start` route using `startRoom`

### Frontend (after backend is running)

5. `frontend/src/services/api.ts` — add `hostId` to `RoomSnapshot`; widen status
   union to include `"active"`; add `startGame(code, participantId)` method
6. `frontend/src/state/roomStore.ts` — add `startGame()` method that calls
   `api.startGame` with stored code and participantId
7. `frontend/src/pages/CreateRoomPage.tsx` — trim + reject empty name before
   calling `roomStore.createRoom`
8. `frontend/src/pages/JoinRoomPage.tsx` — trim + reject empty name before
   calling `roomStore.joinRoom`
9. `frontend/src/pages/LobbyPage.tsx` — replace manual refresh with `setInterval`
   (~2 000 ms) calling `roomStore.fetchRoom()`; navigate to `/game` when
   `room.status === "active"`; show Start Game only when `isHost`; disable Start Game
   when `room.participants.length < 2`; call `roomStore.startGame()` on click

### Validation

10. Two-tab walkthrough per `specs/001-scribble-game/quickstart.md`
11. `npm run build` in both `backend/` and `frontend/` — must exit 0
